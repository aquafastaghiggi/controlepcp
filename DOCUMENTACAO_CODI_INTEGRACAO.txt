💡 EXEMPLOS DE USO EM PHP

1. Carregar Todos os Recursos:
───────────────────────────────
require_once 'src/Database/Connection.php';
use App\Database\Connection;

$pdo = Connection::get();
$result = $pdo->query('SELECT * FROM codi_recursos');
$recursos = $result->fetchAll(PDO::FETCH_ASSOC);

2. Calendário de um Recurso:
────────────────────────────
$stmt = $pdo->prepare(
    'SELECT * FROM codi_calendario WHERE cal_recurso_codi_id = ?'
);
$stmt->execute([10]); // ID do recurso
$calendario = $stmt->fetchAll(PDO::FETCH_ASSOC);

3. Timeline com JOINs:
──────────────────────
$query = 'SELECT c.*, r.cod_nome_recurso 
          FROM codi_calendario c
          LEFT JOIN codi_recursos r ON c.cal_recurso_codi_id = r.cod_codigo_codi
          WHERE c.cal_data BETWEEN ? AND ?';
$stmt = $pdo->prepare($query);
$stmt->execute(['2020-01-01', '2020-12-31']);

4. Chamar API RESTful:
──────────────────────
$url = 'http://localhost/api/codi_data.php?endpoint=recursos';
$response = file_get_contents($url);
$dados = json_decode($response, true);

🔄 FLUXO DE SINCRONIZAÇÃO

1. PHP chama CodiClient.php
   └─ Conecta via HTTP Basic Auth ao CODI
   
2. CodiClient retorna JSON com encoding ISO-8859-1
   └─ Convertido para UTF-8 no CodiClient
   
3. Dados salvos em tabelas codi_*
   └─ Com campo cod_dados_json para dados completos
   
4. APIs servem dados em JSON limpo
   └─ Pronto para frontend/mobile
   
5. Análises/Relatórios processam dados
   └─ Agregações, correlações, filtros

• Paginação: CODI suporta pageNumber=0 e pageSize até 100
• Dados Brutos: Campo cod_dados_json preserva estrutura original CODI
