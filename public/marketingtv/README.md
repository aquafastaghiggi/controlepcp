# Marketing TV

Painel local para enviar imagens e reproduzir um carrossel na TV.

## URLs

- Painel de upload: `http://localhost/marketingtv/`
- Tela da TV: `http://localhost/marketingtv/tv.php`

## Observações

- Sem login.
- Recomendado usar imagens JPEG/PNG em proporção 16:9.
- O tempo do slide é global e pode ser ajustado no painel.
