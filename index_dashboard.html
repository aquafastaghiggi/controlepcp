🔍 Como Funciona

1. Busca Planejado

O dashboard faz requisição para api_integrated.php?action=detalhe_op&op=201055

A API consulta o banco local (prg_itens) e retorna:

  • SKU da OP
  • Quantidade planejada
  • Schedules associados

2. Busca Realizado (CODI)

A mesma requisição chama a função get_codi_order() que:

  • Conecta ao CODI API em http://192.168.8.246:8080
  • Autentica com Aghiggi/@Ag0351@
  • Busca em até 100 páginas (~/50.000 OPs)
  • Retorna dados de OP 0201055 com status INICIADO e quantidade 5.000 un

3. Retorno JSON

A API retorna um JSON estruturado com:

  • planejado: dados do seu sistema
  • realizado: dados da CODI
  • status: indicadores se foi encontrado

4. Renderização Dashboard

O HTML carrega o JSON e renderiza:

  • Card esquerdo: PLANEJADO com informações locais
  • Card direito: REALIZADO com dados da CODI
  • Comparativo: lado a lado + desvio em quantidade e %
